# Storybook для TimeTracker

## 🎨 Установка и запуск

Storybook установлен и настроен для проекта TimeTracker.

### Команды

```bash
# Запустить Storybook в dev режиме
npm run storybook

# Собрать статическую версию Storybook
npm run build-storybook
```

Storybook будет доступен по адресу: http://localhost:6006

## 📚 Структура Stories

### UI компоненты (shadcn/ui)

**Базовые элементы:**
- `Button` - кнопки (все варианты, размеры, состояния)
- `Badge` - бейджи и метки
- `Input` - поля ввода
- `Textarea` - многострочные поля
- `Checkbox` - чекбоксы
- `Switch` - переключатели
- `Avatar` - аватары
- `Separator` - разделители

**Сложные компоненты:**
- `Card` - карточки с различными комбинациями
- `Tabs` - вкладки
- `Select` - выпадающие списки (в составе других компонентов)

### Custom Fields

Реальные компоненты для пользовательских полей документов:

- **TextFieldInput** - текстовые поля (обычные и многострочные)
- **DateFieldInput** - поля выбора даты с иконкой календаря
- **NumberFieldInput** - числовые поля с настройками шага и лимитов
- **SelectFieldInput** - выбор из списка (одиночный и множественный)
- **CheckboxFieldInput** - чекбоксы с метками
- **TagsFieldInput** - поле добавления тегов

Каждый компонент включает:
- Примеры с различными состояниями
- Обязательные и необязательные поля
- Формы с несколькими полями
- Интерактивные примеры

### Features

**Задачи:**
- **TaskCardMain** - карточка задачи с контекстом (header, body, footer)
- **TaskDueDate** - отображение сроков с цветовой индикацией:
  - Красный - просрочено
  - Желтый - срочно (≤3 дня)
  - Обычный - >3 дней

**Таймеры:**
- **TimerButton** - кнопка play/pause с состояниями:
  - Остановлен (зеленая кнопка)
  - Работает (оранжевая кнопка с пульсацией)
  - Загрузка (спиннер)
  - Занят другим пользователем (с индикатором)
- **TimerDisplay** - отображение времени (HH:MM:SS)
  - Различные размеры
  - Интерактивный таймер
  - Примеры в карточках

**Документы:**
- **CommentButton** - кнопка комментариев с счетчиком
- **SidebarSeparator** - разделитель для сайдбара

### Shared компоненты

- **RateItem** - отображение ставки/цены
- **PaymentType** - тип оплаты (фиксированная/почасовая)
- **AdvantageCard** - карточка преимущества
- **OwnerUi** - бейдж "Вы" для владельца
- **UserAvatar** - аватар пользователя с различными размерами

## 🎯 Примеры использования

### Формы с custom fields

```tsx
<TextFieldInput
  field={field}
  value={value}
  onChange={(val) => setValue({ value: val })}
/>
```

### Карточка задачи

```tsx
<TaskCardMain.Root {...taskData}>
  <TaskCardMain.Header />
  <TaskCardMain.Body />
  <TaskCardMain.Footer />
</TaskCardMain.Root>
```

### Таймер

```tsx
<TimerButton
  isPlaying={isPlaying}
  onToggle={() => setIsPlaying(!isPlaying)}
/>
```

## 📝 Советы по разработке

1. **Создание новой story:**
   - Файл должен иметь расширение `.stories.tsx`
   - Размещать рядом с компонентом
   - Использовать типы из Storybook

2. **Именование:**
   - `title` определяет путь в навигации
   - Используйте слеш для группировки: `'Features/Tasks/TaskCard'`

3. **Демонстрация состояний:**
   - Создавайте отдельные stories для разных состояний
   - Используйте `render` для интерактивных примеров
   - Показывайте edge cases

4. **Моки данных:**
   - Создавайте реалистичные моки
   - Используйте различные варианты данных
   - Показывайте пограничные случаи
